## Export Steps

1. **Verify sources.** Read the reference checksums from the files committed on `main` (Alibaba `verification/artifact_manifest.json` and `final_test/run_record.json`; Google `decision_manifest.json`), hash every input and refuse any mismatch. With `--allow-unverified-source`, continue, list the mismatches and mark the bundle `development`.
2. **Google.** Baselines, `uses_history_*` flags and history counts from `test_occurrences.parquet`; ML from `test_ml_predictions.parquet`; Hybrid through `hybrid_recommendation(ML, P95)`, checked equal to the stored Hybrid on all 259 scored rows; target statuses derived as specified in the issue.
3. **Alibaba.** Predictions from `final_test_predictions.parquet`; start times from the Task 4 test table and history flags from the Task 6 test recommendations, both joined one-to-one on `role_key`; reshaped from one row per run to one row per run and policy.
4. **Build outputs.** Basis per resource and policy; `is_latest` (exactly one per workload); `workloads.parquet`; `policy_metrics.json` copied from the summary CSVs; `rules.json` copied from the frozen records; `dataset.json`; `metadata.json`; `manifest.json`; `SHA256SUMS`.
5. **Validate, then write.** Every copied value equals its source; row counts; nulls preserved; latest-run fallback counts match. Write to a staging folder, then rename into place.

## Choices

| Choice | Decision |
|---|---|
| Dataset IDs | `google_clusterdata2019` and `alibaba_gpu_v2020`, as in the capability profiles and Task 12 |
| Policy names | Summary-CSV names (`Request` … `Hybrid`) in the bundle; lowercase `policy_id` in the API |
| Output location | Default `reports/results/ui/`; during development `data/processed/ui_dev/` (git-ignored), so a `development` bundle cannot be committed by accident |
| API framework | FastAPI with Uvicorn; OpenAPI generated by FastAPI |
| CORS | Not enabled; added only if Task 16 chooses a separate frontend server |
